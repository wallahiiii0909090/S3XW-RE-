# S3XWÀRE

A Blade Ball script hub for Roblox with advanced automation features like auto parry, AI player behavior, anti-lag options, and more.

## Features
- Auto Parry & Spam
- AI Player Movement
- Visualizer & Ball Trails
- Auto Farm Modes
- Manual and Ping-Based Modes
- Anti-AFK, BunnyHop, Fly, and Misc Tweaks

## Usage
Inject the script via a supported Roblox executor.

Use at your own risk.
